# 黄缘龟桌宠

> 一只黄缘龟会在你的 Windows 任务栏上爬行

---

## 一、功能特性


1.多帧走路动画
2.交互功能
  - 左键拖拽：移动乌龟位置
  - 左键单击：缩壳
  - 滚轮：调节爬行速度
  - 右键菜单：关于、退出


---

## 二 运行方式

### 方式一：下载源文件后一键启动（推荐）
双击 **`启动桌宠.bat`** 即可运行

### 方式二：下载源文件使用命令行
```bash
pip install PyQt5
python 黄缘龟桌宠.py
```

### 方式三：下载可执行程序
下载完成exe文件后后双击即可启动


---



## 关于本程序
需安装的python库:
1.PyQt5>=5.15.0

2.Pillow>=10.0.0

3.numpy>=1.24.0

4.python-pptx>=1.0.0

**黄缘盒龟（Cuora flavomarginata）** 是国家二级保护动物，
特征：
- 背甲呈深茶褐色，圆拱形
- 背甲中央有明显金黄色脊线
- 头部为橄榄绿，两侧有金黄色条纹
- 腹甲黄色，边缘黑色

> ⚠️本程序虽完成了缩壳动画，但未完能像现实中的黄缘龟那样完全闭壳，可自行继续完善
